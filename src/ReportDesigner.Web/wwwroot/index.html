Éléments

Glissez un élément dans une bande, ou cliquez pour l'ajouter à la bande sélectionnée.

Champs (données)

    Bandes

      Aligner :

      Données d'exemple utilisées pour l'aperçu et enregistrées avec le modèle. Format : tableau de lignes, ou { "parameters": {…}, "rows": [ … ] }.

      Expressions

      Tout texte peut contenir des expressions entre accolades, avec un format .NET optionnel après « : ».

      {nom}, {client.ville}champ (chemin pointé)
      {[nom complet]}champ dont le nom contient des espaces
      {prix:N2}, {date:dd/MM/yyyy}valeur formatée
      {$P.titre}paramètre
      {qte * prix:N2}calcul : + - * / %
      {nom + ' (' + ville + ')'}concaténation de textes
      {IF(montant > 1000, 'Gros', 'Petit')}condition : = != < <= > >=, and or not
      {SUM(qte * prix):N2}agrégat sur une expression (aussi AVG, MIN, MAX, COUNT, COUNT_DISTINCT, FIRST, LAST)
      {SUM(montant, 'report')}portée : 'report', 'group1', 'group2'…
      {COUNT()}nombre de lignes
      {$PAGE} / {$PAGES}numéro de page / total
      {$DATE}, {$NOW:HH:mm}date / heure de génération
      {$ROW}, {$GROUP_ROW}n° de ligne (rapport / groupe)
      {$GROUP}, {$GROUP1}…valeur du groupe courant / d'un niveau
      {actif:Oui|Non}libellés d'un booléen
      {{ }}accolades littérales

      Fonctions : IF, COALESCE, ISNULL, ISEMPTY · ROUND, FLOOR, CEILING, ABS, MIN, MAX, NUMBER · UPPER, LOWER, TRIM, LEN, LEFT, RIGHT, SUBSTR, REPLACE, CONTAINS, STARTSWITH, ENDSWITH, CONCAT, FORMAT · DATE, YEAR, MONTH, DAY, ADDDAYS, ADDMONTHS, DATEDIFF.

      Les agrégats portent par défaut sur le groupe courant dans les bandes de groupe et le détail, sinon sur tout le rapport.

      Conditions et valeurs calculées

      • Afficher si (élément) / Imprimer si (bande) : remise > 0, $PAGE > 1…
      • Couleurs : {IF(montant < 0, '#DC2626', '#000000')}.
      • Image provenant des données : {photo} (data URL ou base64).

      Bandes

      • Titre : une fois, au début.
      • En-tête de page / Pied de page : sur chaque page.
      • En-tête de colonnes : répété au-dessus des lignes sur chaque page.
      • Détail : une fois par ligne de données.
      • En-tête / Pied de groupe : autour de chaque groupe (champ « Regrouper par »).
      • Résumé : une fois, à la fin.

      Éléments extensibles (case « Extensible ») : un texte long agrandit sa bande au lieu d'être tronqué ; les éléments situés dessous descendent, et les cadres ou séparateurs verticaux extensibles s'étirent avec la bande.

      Raccourcis

      • Suppr supprimer · Flèches déplacer (Maj = 10 pt)
      • Ctrl+C/V/D copier / coller / dupliquer
      • Ctrl+Z/Y annuler / rétablir · Ctrl+A tout sélectionner dans la bande
      • Maj+clic : sélection multiple · glisser sur le fond : sélection par zone

      API

      POST /api/reports/{nom} avec vos données JSON renvoie le PDF du modèle enregistré.
